# AccesibilidadWeb para Gemini CLI

Para auditar o adaptar la accesibilidad de una web (WCAG 2.2 AA, EN 301 549, Ley 11/2023, RD 1112/2018), sigue **@skills/accesibilidad-web/SKILL.md**. Es la fuente única: no dupliques aquí sus pasos.

Resumen: detectar stack → `node skills/accesibilidad-web/scripts/auditar.mjs <url>` → revisión manual guiada → arreglos por impacto con las recetas de `skills/accesibilidad-web/references/` → declaración (`docs/declaracion-accesibilidad-plantilla.md`) → informe con criterios citados.

Para contribuir a este repositorio, lee `AGENTS.md` y `CONTRIBUTING.md`.
